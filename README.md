# ABME

`abme` 现在定位为一个可复用的 agent 调试工作台仓库。

它保留的内容只服务三类目标：

- 说明 agent 系统的整体结构
- 维护思源资源层和调试工作台的接入规范
- 提供可复用的模板、规则和图示

它同时承接三类持续动作：

- 维护 `J.A.R.V.I.S.` 与各主合伙人的人格与可调教机制
- 记录关键工作会话纪要，而不是保存原始聊天流水
- 作为一个可持续同步到 GitHub 的工作仓库持续演进

## 当前目录

- `SOLUTION_ARCHITECTURE.md`：总体架构说明
- `ROADMAP.md`：当前路线图
- `mind_framework.md`：方法论层的简化说明
- `docs/`：架构、接口、接入规范、工作台说明
- `docs/session-notes/`：结构化工作会话纪要
- `diagrams/`：当前结构图
- `.agent/rules/`：项目内通用规则
- `标准/siyuan/`：思源模板

## 已清理内容

以下内容已从仓库移除，因为它们过于个人化、临时化或已经过时：

- 临时原始资料
- 不可复用的原始聊天记录和历史流水
- 敏感文件
- 旧架构图与旧规范文档
- 与当前定位无关的专用技能和旧规则

## 设计原则

1. 尽量保留可复用资产，不保留一次性材料。
2. 仓库负责结构和规范，不负责长期存放个人运行痕迹。
3. 调试记录优先回写思源 `11-Agent Debug`，而不是堆在仓库里。
4. 仓库允许保存“结构化工作会话纪要”，但不保存无整理的原始聊天导出。
5. 所有人格调整都应能被记录、比较、回滚和继续调教。

## 运行约定

- 角色提示词的规则真源在思源 `00-Core`
- 调试过程与运行反馈优先进入思源 `11-Agent Debug`
- 仓库中的 `docs/session-notes/` 用于记录关键会话摘要、决策和下一步动作
- 仓库默认应保持可 git 初始化、可提交、可推送到 GitHub
