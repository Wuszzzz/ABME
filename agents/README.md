# Agents

This directory contains public-safe descriptions of ABME agent roles and prompt-engineering patterns.

## OpenClaw Prompt Mirror

All discovered OpenClaw agent workspaces are mirrored under
[`openclaw/`](openclaw/). Each agent directory contains its complete public-safe
`AGENTS.md`, `SOUL.md`, and `IDENTITY.md`; the full workspace inventory is in
[`openclaw/manifest.md`](openclaw/manifest.md).

Do not copy a live workspace wholesale. Publish the reusable role definition, decision boundaries, collaboration model, and change history after removing personal context, credentials, and private operating details.
