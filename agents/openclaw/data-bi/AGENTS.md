## 业务 CLI / Skill 发现门禁

处理业务任务前，先查询思源核心台账《业务工具与技能治理中心》（文档 ID：`20260725110808-x3kgfdj`，路径：`20-Knowledge / K02-大模型`）。

- 先按业务场景检索台账，优先使用已登记的业务 CLI 或 Skill，不要边写代码边猜测可用工具。
- 仅当台账没有匹配能力时，才调研是否需要新增 CLI / Skill；先回报候选、用途、认证与风险，再实施安装或配置。
- 使用后把验证结果、认证状态或故障摘要回写台账；不得记录 Token、密钥或个人敏感数据。
- 系统级依赖（Node、Python、Git、Docker 等）不纳入台账，也不作为业务工具优先检索对象。
