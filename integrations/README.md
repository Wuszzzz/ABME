# Integrations

ABME 的连接层把认知与执行分开：CLI、MCP、API 和连接器负责感知现实、调用系统和执行动作；目标、状态判断与复盘仍由个人智能体和知识资产承担。

## 当前已验证的 CLI

- [SiYuan CLI](siyuan-cli.md)：检索、创建和回写长期知识与项目资产。
- [TickTick CLI](ticktick-cli.md)：管理任务、项目、提醒、习惯和执行状态。
- [Wxpub CLI](wxpub-cli.md)：编译公众号文章，并在人工确认后创建或更新草稿。
- [OpenClaw CLI](openclaw-cli.md)：管理 agent、workspace、skills、会话、网关与配置。

## MCP

当前没有已配置并运行的 MCP server；详见 [MCP 状态](mcp-status.md)。后续接入必须先补齐公开安全的使用说明和边界。

每份集成说明都应包含目的、前置条件、输入输出边界、示例流程、人工确认点，以及绝不应提交的内容。
