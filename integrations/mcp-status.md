# MCP Status

## 当前结论

截至本次盘点，ABME 没有发现已配置并正在使用的 MCP server。当前已投入使用的连接能力主要是 CLI：SiYuan、TickTick、Wxpub 和 OpenClaw。

## 已排除项

公众号工程中曾出现过 WeChat/`fastmcp` 相关的旧虚拟环境和入口，但当前没有发现有效的 MCP 配置，也不将其视为运行链路。公众号草稿能力以 `wxpub` CLI 和官方接口连接器为准。

## 接入 MCP 的条件

新增 MCP 前，需要在本目录新增一份说明，明确：

1. 它感知或执行什么能力；
2. 所需权限、数据边界和人工确认点；
3. 配置位置及密钥的私有存放方式；
4. 失败时的降级路径；
5. 哪些部分可以公开同步，哪些必须排除。

MCP 是连接层，不是认知层；它为 agent 提供感知与行动接口，不替代目标、判断和回写闭环。
