# ABME 调试工作台说明

## 1. 项目定义

`abme` 是 agent 系统的本地调试工作台。

它服务于两个目标：

- 维护和调试提示词体系
- 维护和调试多角色协作体系

## 2. 日常工作内容

### 提示词调试

- 主 agent 提示词调整
- 主合伙人提示词调整
- 子 agent 提示词调整
- 提示词版本差异对比

### 工作流联调

- 角色间路由是否合理
- 哪些动作归 `J.A.R.V.I.S.`
- 哪些动作归具体合伙人
- 飞书中的实际表现是否符合设计

### 运行复盘

- 飞书层哪些地方跑顺了
- 哪些地方误判了
- 哪些地方链路断了
- 哪些问题要升级回规则层

## 3. 与思源的关系

思源不是 `abme` 的附属文档库，而是上位资源层。

`abme` 的主要动作之一，就是把调试结果正确回写到思源：

- 调试中的东西进 `11-Agent Debug`
- 稳定方法进 `20-Knowledge`
- 稳定规则进 `00-Core`

## 4. 与飞书的关系

飞书是运行层。

`abme` 不是去替代飞书角色，而是：

- 为飞书角色提供规则和结构
- 接收飞书层反馈
- 基于真实问题做修正

## 5. 当前最重要的产物

`abme` 当前应该优先产出：

- 结构清晰的架构文档
- 可执行的调试流程
- 统一的记录模板
- 可追踪的升级历史
