# 会话纪要说明

这个目录用于保存 `abme` 项目中的结构化工作会话纪要。

这里不保存原始聊天流水，只保存适合进入工程历史的摘要：

- 本次讨论目标
- 关键判断
- 做出的结构调整
- 尚未解决的问题
- 下一步动作

## 记录原则

1. 一次重要推进记一篇，不追求每句话都存。
2. 内容要可复用、可回顾、可追责。
3. 稳定规则最终仍要升级到思源，不让仓库替代思源真源。

## 推荐命名

- `YYYY-MM-DD-主题.md`

例如：

- `2026-05-06-second-brain-gap-review.md`
- `2026-05-06-agent-personality-and-tuning.md`
